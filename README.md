## 🎶 Tentang Proyek

**Code-Song** adalah proyek kreatif yang menggabungkan pemrograman dengan seni musik. Program ini dirancang untuk menampilkan lirik lagu (seperti lagu Natal dan berbagai lagu pilihan lainnya) secara interaktif mengikuti alur waktu, tempo, atau nada lagu yang sedang dimainkan.

---

## ✨ Fitur Utama

* **Sinkronisasi Lirik** : Menampilkan lirik lagu secara bertahap sesuai dengan tempo atau hitungan waktu.
* **Format Python** : Dibangun menggunakan skrip Python yang bersih dan mudah dimodifikasi.
* **Kustomisasi Lagu** : Memungkinkan penambahan lagu atau lirik baru dengan mudah ke dalam sistem.
